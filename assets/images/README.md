# صور المشاريع

ضع هنا صور المشاريع بصيغة **WebP** (مضغوطة، عرض 800px كحد أقصى ما لم تكن لقطة شاشة طويلة).

## طريقة الإضافة الصحيحة

1. ضع ملفات الصور هنا: `assets/images/projects/<project-id>/1.webp`، `2.webp` ...
2. أضف مدخلاتها إلى `gallery` في `data/projects.json` (الاسم + الوصف البديل لكل صورة).
3. تحقق قبل النشر: `node tools/check-assets.mjs` — يفشل إذا أشار أي مسار إلى ملف غير موجود.

قاعدة صارمة: **المعرض يعرض فقط ما هو مذكور في البيانات، والبيانات لا تذكر إلا ما هو موجود فعلاً على القرص.** لا صور وهمية، ولا مكان شاغر.

- الصورة الشخصية عند توفرها: `assets/images/profile.webp` (1:1، 400px).

## بطاقات المشاركة (Open Graph)

`assets/images/og/` يضم بطاقة المشاركة `og-default.png` (1200×630) التي تُعلنها
صفحات الموقع عبر وسم `og:image`. تُولَّد بالكود لا باليد — عدّل القالب في
`tools/generate-og.mjs` ثم أعد التشغيل:

```
node tools/generate-og.mjs
```

بعد أي توليد أو إزالة بطاقة، تحقق قبل النشر: `node tools/check-assets.mjs` يرفض
أي صفحة `og:image` تشير إلى ملف غير موجود.
